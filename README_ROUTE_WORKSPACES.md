# Language Goal OS — Route Workspaces + Parent/Child UX

This package keeps the adult flow stable and adds the next architectural layer:

- Route-specific visual themes for paid workspaces.
- Separate school/child experience.
- Parent dashboard preview and child progress dashboard.
- Child interface simplification: Setup / Mission / Phrases / For parent.
- Child sees a light voice mission with Lingua Buddy; parent sees statistics, dynamics and recommendations.
